# NTIN Catalog Automation

Автоматизация работы магазина с **Национальным каталогом товаров Казахстана** (коды NTIN): интеграция с государственным API каталога, Telegram-бот для сотрудников и ИИ-помощник, который по фото упаковки находит готовую карточку или готовит новую и сам отправляет её на модерацию.

Проект работает в реальном магазине: продавцы проверяют товары через бота сами, без участия разработчика.

## Что умеет

**Telegram-бот для сотрудников** (`bot.py`)
- штрихкод цифрами или фото → готовый код NTIN из каталога или нашей базы;
- проверка контрольной цифры GTIN, распознавание внутренних магазинных штрихкодов;
- поиск по названию по всему открытому каталогу, затем по своей базе;
- список «нужно зарегистрировать», выгрузка в CSV (с защитой от формул Excel);
- вход по коду приглашения с ограничением попыток, отдельные команды администратора;
- память выбора: если на штрихкод несколько карточек, выбор сотрудника запоминается.

**ИИ-помощник «Добавить товар»** (`ai_add.py`, `ai_flow.py`)
- модель читает упаковку по фото и возвращает строгий JSON (с повтором при неразборчивом ответе);
- ищет похожие карточки в каталоге и оценивает совпадение по ключевым словам;
- если готовой карточки нет, подбирает страну, категорию ОКТРУ и код ТН ВЭД по справочникам (поиск по полному пути классификатора, ИИ выбирает вариант по смыслу или отвечает «ничего не подходит»);
- сотрудник подтверждает черновик кнопками «Верно / Исправить»;
- лимиты: запросов в день на человека и месячный бюджет, учёт стоимости каждого запроса.

**Работа с API каталога** (`nkt_client.py`, `submit.py`, `submitter.py`)
- авторизация по ключу, повторы при HTTP 429 и 5xx с учётом `Retry-After`, понятные ошибки 401/422;
- загрузка справочников (ОКТРУ, ТН ВЭД, страны, единицы — более 110 тыс. записей) с продолжением с места остановки;
- создание заявки, проверка дублей, отправка на модерацию, слежение за статусом и публикация;
- автоотправка с суточным лимитом и паузой по команде администратора.

**Подготовка данных** (`import_supplier.py`, `check_ntin.py`, `audit_base.py`, `clean_base.py`, `match_names.py`)
- импорт готовых кодов из прайсов поставщиков и выгрузок 1С (восстановление ведущих нулей, срезанных Excel);
- сверка базы с каталогом: отключённые карточки, дубликаты, замены;
- пакетный подбор кодов по списку названий из Excel с цветным отчётом.

## Стек

Python 3 · requests · SQLite (WAL) · pandas · openpyxl · OpenCV · Telegram Bot API (без фреймворков) · Anthropic API (Claude Haiku) · pytest · Linux, systemd, SELinux

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот: логика ответов (класс `Brain`) отделена от Telegram, поэтому легко тестируется |
| `ai_add.py` | запросы к модели, разбор ответа, сопоставление с карточками, выбор кодов |
| `ai_flow.py` | сценарий «Добавить товар» в боте: фото → черновик → подтверждение |
| `submitter.py` | автоотправка заявок в каталог и слежение за модерацией |
| `nkt_client.py` | клиент API каталога с повторами и паузами |
| `card.py` | сборка и проверка заявки на карточку по правилам каталога |
| `oktru.py`, `dicts.py` | локальные справочники и поиск по ним |
| `check_ntin.py` | проверка штрихкодов по открытому каталогу, логика статусов |
| `match_names.py` | пакетный подбор кодов по названиям |
| `import_supplier.py`, `audit_base.py`, `clean_base.py` | подготовка и чистка базы кодов |
| `submit.py`, `export_drafts.py` | ручной путь регистрации карточки из командной строки |
| `deploy_bot.sh` | выкладка на сервер (`NTIN_SERVER=user@host ./deploy_bot.sh`) |

## Тесты

```bash
python -m venv venv && . venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest -q
```

176 проверок. Тесты не ходят в интернет: каталог, модель и Telegram подменяются заглушками. Покрыто:
статусы кодов и дубли карточек, контрольные цифры и внутренние штрихкоды, сборка карточки и ошибки валидации,
поиск по справочникам, разбор ответов модели и повторы, ошибки API (401, 429, 5xx, 422), доступ и вход по коду,
лимит штрихкодов в сообщении, скрытие токена в журнале, пакетный подбор и импорт прайсов.

## Безопасность

- ключи только в `.env` (в Git не попадает, пример — `.env.example`);
- токен бота вырезается из журнала, включая текст ошибок;
- доступ к боту — по списку или коду приглашения с ограничением попыток;
- базы кодов, фото и данные магазина в репозиторий не входят.

## Запуск

```bash
cp .env.example .env      # заполнить ключи
python oktru.py download  # справочник ОКТРУ (один раз)
python dicts.py download COUNTRY MEASURE_UNIT TNVED
python bot.py
```
