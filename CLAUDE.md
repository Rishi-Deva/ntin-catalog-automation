# Правила работы агента в этом проекте

## О проекте
Автоматизация работы с Национальным каталогом товаров Казахстана: Telegram-бот, ИИ-помощник,
интеграция с государственным API. Python 3, SQLite, pytest. Описание модулей — в README.md.

## Как работать над задачей
1. Перед тем как писать код, создай план в `plans/<короткое-имя-задачи>.md` по шаблону `plans/TEMPLATE.md`:
   цель, критерий готовности, шаги с чекбоксами.
2. Работай строго по шагам: один шаг → прогон тестов → отметь шаг `[x]` → запиши строку в журнал плана.
3. Если тест упал или выяснилось что-то новое — СНАЧАЛА обнови план (добавь или измени шаги)
   и запиши в журнал, что изменилось и почему. Только потом продолжай. Никаких молчаливых изменений.
4. Задача готова, когда: критерий готовности выполнен, ВСЕ тесты зелёные, все шаги плана закрыты.
5. В конце дай короткий итог: что сделано, что изменилось в плане по ходу, какие файлы затронуты.

## Команды
- Тесты: `~/ntin-public/venv/bin/python -m pytest -q` (запускать из корня текущей папки проекта).
- Тесты не ходят в сеть: каталог, ИИ и Telegram подменяются заглушками в `tests/`.

## Запреты
- Не читать, не создавать и не показывать `.env`. Никаких ключей и токенов в коде, логах и тестах.
- Не обращаться к реальным API в тестах — только заглушки.
- Не делать `git push`. Коммит — только когда человек попросит.
- Не подгонять тесты под код, чтобы они «просто прошли». Если тест меняется — объясни в журнале плана почему.

## Стиль
- Маленькие изменения, понятные имена.
- Не дублировать логику: если нужная функция уже есть в проекте — переиспользуй её.
